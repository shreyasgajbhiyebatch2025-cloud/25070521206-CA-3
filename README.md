# Med-Sathi Clinical eMAR Project (25070521206)

Full-Stack Closed-Loop Inpatient Medication Administration & Patient Safety Platform.

## Directory Structure
```
25070521206/
├── client/   # React 18 + Vite + Tailwind CSS Frontend
└── server/   # Node.js + Express + MongoDB Resilient Engine
```

## Quick Start
```bash
# Terminal 1: Backend Server (Port 5000)
cd 25070521206/server
npm install
npm run dev

# Terminal 2: Frontend Web App (Port 3000)
cd 25070521206/client
npm install
npm run dev
```

Open `http://localhost:3000` to access the application.
